# Terraform Refactor

This folder contains the Terraform version of the AWS infrastructure built manually in Phase 1 of this project.

The goal of this phase is to convert the manually created AWS environment into infrastructure as code so that the entire setup can be deployed in a repeatable and version-controlled way.

Through this refactor I’m learning how Terraform manages infrastructure using:

- providers
- resources
- variables
- outputs
- state
- the plan and apply workflow

The Terraform configuration in this folder will gradually recreate the networking and compute components from the earlier phase of the project.
